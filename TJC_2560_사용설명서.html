TJC 터치 화면 + Mega2560 사용설명서

TJC X2 시리즈 7인치 터치 화면(TJC8048X270_011)으로 메가2560의 릴레이 16개를 현장에서 직접 누르고 상태를 보는 방법입니다.

1. 전체 구성 2. 준비물 3. 시작 순서 4. 배선 5. 화면 만들기 6. 통신 시험 7. 펌웨어 올리기 8. 사용법 9. 문제 해결 10. 주의사항

1. 전체 구성

이 시스템은 역할이 둘로 나뉩니다.

  • 웹 페이지(2560.html) — PC에서 핀, 시퀀스, 센서를 설정하는 도구입니다.
  • TJC 터치 화면 — 설정이 끝난 뒤 현장에서 운전하는 조작판입니다.

화면을 눌러 릴레이를 바꾸면 웹 페이지와 시퀀스, 키패드로 바뀐 릴레이도 화면 버튼에 같이 표시됩니다. 둘은 같은 릴레이 상태를 함께 봅니다.

2. 준비물

  • Arduino Mega 2560 + 16채널 릴레이 보드
  • TJC8048X270_011 (X2 시리즈 7인치) 및 전원 (사양은 데이터시트 확인)
  • USB-TTL 변환기 (통신 시험용, 3.3V/5V 전환 가능한 것이 편리)
  • 점퍼선, 저항 2kΩ·1kΩ 각 1개 (화면이 3.3V 로직일 때)
  • PC와 Chrome 또는 Edge 브라우저, 아두이노 IDE, TJC 편집기 USART HMI
  • 파일: TJC_통신시험.html, Mega2560_16Relay_Firmware_keypad_TJC.ino, 2560.html(웹 설정 도구)

3. 시작 순서

문제가 생겼을 때 원인을 나누기 쉽도록, 아래 순서를 지켜 한 단계씩 확인하세요.

  1. 화면 편집기에서 화면 만들기 (5번)
  2. PC와 화면만 연결해서 통신 시험 (6번)
  3. 메가에 펌웨어 올리고 화면과 연결 (7번)
  4. 릴레이 1~2개로 시험한 뒤 전체 연결 (8번)

4. 배선

메가2560 ↔ 화면

메가2560화면설명
TX3 (핀 14)RX메가 → 화면
RX3 (핀 15)TX화면 → 메가
GNDGND반드시 공통 연결

화면 전원은 데이터시트의 사양대로 따로 공급하세요. 메가의 5V 핀에서 무작정 끌어 쓰지 마세요.

전압 주의 — 메가는 5V 로직입니다. 화면이 3.3V 로직이면 메가 TX3(14) → 화면 RX 선에 저항 분배(2kΩ와 1kΩ)를 넣어 전압을 낮춰야 합니다. 반대 방향(화면 TX → 메가 RX3)은 그대로 연결해도 됩니다. 전압은 반드시 모델 데이터시트에서 먼저 확인하세요.
핀 14·15번은 화면 통신 전용입니다. 릴레이나 입력 채널에 지정하지 마세요. 웹 페이지의 "12. 배선도"가 이 핀을 쓰면 빨간 경고를 띄웁니다.

PC ↔ 화면 (시험용)

USB-TTL 변환기의 TX → 화면 RX, 변환기 RX → 화면 TX, GND 공통입니다. 이때 메가는 연결하지 않아도 됩니다.

5. 화면 만들기 (USART HMI)

화면 디자인은 웹이 아니라 전용 편집기에서만 만들 수 있습니다.

  1. USART HMI에서 새 프로젝트를 만들고 모델 TJC8048X270_011을 선택합니다.
  2. page 0에 2상태 버튼(Dual-state button) 16개를 배치합니다.
  3. 버튼 이름(objname)을 bt1, bt2, … bt16으로 지정합니다.
  4. 컴포넌트 ID를 1~16이 되게 맞춥니다. 속성 창에서 확인할 수 있고, 만든 순서대로 번호가 매겨집니다.
  5. 각 버튼의 "누름 이벤트"에서 Send Component ID를 체크합니다.
  6. 통신속도는 9600으로 둡니다.
  7. 컴파일한 뒤 화면에 올립니다 (SD카드 또는 편집기에서 직접 — 방법은 제품 설명서를 따르세요).
버튼 이름이 r1처럼 다르면 화면과 메가가 서로 알아보지 못합니다. 반드시 bt1~bt16이어야 합니다.

한글 글자를 화면에 표시하려면 한글이 들어 있는 폰트를 따로 만들어야 합니다. 먼저 영문과 숫자로 시험하세요.

6. 통신 시험 (PC와 화면만)

  1. 화면을 USB-TTL 변환기로 PC에 연결합니다.
  2. Chrome이나 Edge에서 TJC_통신시험.html을 엽니다.
  3. 통신속도 9600을 선택하고 연결을 누릅니다.
  4. page 0을 보내 화면이 반응하는지 봅니다. 끝의 FF FF FF는 자동으로 붙습니다.
  5. bt1.val=1을 보내 버튼 1번이 눌린 모양으로 바뀌는지 봅니다.
  6. 화면의 버튼을 직접 눌러 아래 기록에 "터치 이벤트: 페이지 0, 컴포넌트 1, 눌림" 같은 줄이 뜨는지 확인합니다.

이 세 가지가 되면 화면은 정상입니다. 안 되면 8번을 먼저 하지 말고 9번 문제 해결을 보세요.

7. 펌웨어 올리기

먼저 백업하세요. 지금 보드에 올라가 있는 펌웨어 파일을 따로 보관해 두세요. 문제가 생기면 그 파일을 다시 올려 원래대로 돌릴 수 있습니다.
  1. 아두이노 IDE에서 Mega2560_16Relay_Firmware_keypad_TJC.ino를 엽니다.
  2. 보드를 Arduino Mega or Mega 2560으로 선택합니다. 라이브러리 U8g2가 설치되어 있어야 합니다.
  3. 먼저 확인(컴파일)만 눌러서 오류가 없는지 봅니다. 오류가 나면 그 메시지를 알려주세요.
  4. 이상이 없으면 업로드합니다.
  5. 메가를 화면에 연결하고 전원을 켭니다. 약 2.5초 뒤 화면에 현재 릴레이 상태가 표시됩니다.

웹 페이지(2560.html)는 이전과 똑같이 연결해서 쓰면 됩니다. 이 펌웨어도 같은 명령에 응답합니다.

8. 사용법

  • 릴레이 켜기/끄기 — 화면의 버튼(bt1~bt16)을 누르면 R1~R16이 토글됩니다.
  • 상태 확인 — 버튼이 눌린 모양이면 릴레이 ON입니다.
  • 웹이나 시퀀스로 바뀐 경우 — 화면 버튼도 자동으로 따라 바뀝니다.
  • 설정 변경 — 핀 번호, 시퀀스, 릴레이 방식 등은 PC의 웹 페이지에서 바꿉니다. 화면에서는 바꿀 수 없습니다.

처음 시험할 때는 릴레이 1~2개만 연결하고 화면 버튼 1, 2번만 눌러 보세요. 정상이면 나머지를 연결합니다.

9. 문제 해결

증상확인할 것
통신 시험에서 아무 반응이 없다TX/RX가 서로 엇갈려 연결됐는지(변환기 TX → 화면 RX), GND 공통, 통신속도 9600, 화면 전원
"잘못된 변수 이름(1A)"이 뜬다통신은 정상입니다. 화면 편집기의 컴포넌트 이름과 보낸 이름이 같은지 확인
화면 버튼을 눌러도 기록에 터치가 안 뜬다버튼 "누름 이벤트"의 Send Component ID 체크
버튼을 눌러도 릴레이가 안 움직인다버튼 이름이 bt1~bt16인지, ID가 1~16인지, 메가 TX3/RX3 배선, 펌웨어가 _TJC 버전인지
릴레이는 움직이는데 화면 표시가 안 바뀐다메가 TX3(14) → 화면 RX 배선, 3.3V/5V 레벨 변환
ON과 OFF가 반대로 동작한다웹 페이지 "2. 릴레이 방식"에서 HIGH형/LOW형을 바꾸세요
부팅 직후 화면 표시가 비어 있다화면 부팅이 늦은 경우입니다. 화면이 켜졌다고 알려오면 다시 보내므로 잠시 기다려 보세요
웹 페이지에서 14·15번에 빨간 경고정상입니다. 두 핀은 화면 통신 전용이라 다른 용도로 쓸 수 없습니다

10. 주의사항

  • 펌웨어를 올리기 전에 기존 펌웨어를 반드시 백업하세요.
  • 화면의 전압(3.3V/5V)과 전원 사양은 구매하신 모델의 데이터시트로 직접 확인하세요.
  • 릴레이에 모터나 히터 같은 큰 부하를 연결하는 작업은 정격과 전원 배선을 확인하고, 안전을 위해 처음에는 부하 없이 시험하세요.
  • 웹 설정 도구(2560.html)로 USB 연결을 열면 메가가 자동으로 재시작되어 릴레이가 모두 꺼집니다. 가동 중인 장비가 있으면 연결하기 전에 멈추세요.
  • 화면 터치는 원격 제어가 아니라 현장 조작입니다. 기계를 움직이는 릴레이는 주변에 사람이 없는지 확인한 뒤 누르세요.
  • 이 설명서와 프로그램은 실제 장비로 충분히 시험된 것이 아닙니다. 처음 연결할 때는 위 순서대로 한 단계씩 확인하세요.
