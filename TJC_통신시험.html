TJC 화면 통신 시험

PC에 USB-TTL 변환기로 TJC 화면을 연결해서 명령을 보내고 응답을 확인합니다. Chrome 또는 Edge에서 파일을 열어 사용하세요.

1. 연결

연결 안 됨
화면 기본 속도는 보통 9600입니다. 변환기 배선: 변환기 TX→화면 RX, 변환기 RX→화면 TX, GND 공통. 변환기 전압(3.3V/5V)은 화면 데이터시트에 맞추세요.

2. 명령 보내기

t0, n0 같은 이름은 편집기에서 만든 컴포넌트 이름입니다. 없는 이름이면 화면이 "잘못된 변수(1A)" 응답을 돌려줍니다. 한글 글자는 화면 폰트가 UTF-8일 때만 보이므로, 먼저 영문으로 시험하세요.

3. 송수신 기록

화면에서 버튼을 눌렀을 때 65 로 시작하는 터치 이벤트가 오면, 해당 페이지 번호·컴포넌트 번호·눌림/뗌을 풀어서 보여줍니다. (버튼의 "Send Component ID" 옵션이 켜져 있어야 옵니다)
