DNMEB50 + Mega2560 웹 제어 사용설명서

2560_DNMEB50.html 화면의 카드 순서(1~14번)에 맞춰 설명합니다. 화면의 버튼 이름은 이런 모양으로 표시했습니다.

0. 준비1. 보드 알기2. 빠른 시작3. 카드별 사용법4. 시퀀스5. 독립 작동6. 점검·진단7. 문제 해결8. 안전

0. 준비물

  • DNMEB50 확장 보드(12V 또는 24V 버전) + 그 위에 얹은 Mega2560 R3
  • USB 케이블, 보드 전원(보드에 쓰인 12V/24V 중 해당 전압)
  • Chrome 또는 Edge 브라우저(Web Serial 기능 필요). 파이어폭스·사파리는 연결이 안 됩니다.
  • 보드에 올릴 펌웨어: DNMEB50_Mega2560_Firmware.ino (릴레이·입력·키패드 끄기가 이 보드 기본값으로 들어 있음)
⚠ DNMEB50은 확장 보드일 뿐이라 단독으로 동작하지 않습니다. 반드시 Mega2560이 얹혀 있어야 합니다.

1. 보드 알아두기

ℹ 판매처 설명 글에는 릴레이가 41~27번, MOS가 43~53번으로 적혀 있습니다. (보드 이미지의 표는 둘이 바뀌어 적혀 있었습니다.) 실제로 웹에서 R1을 눌러 K1이 딸깍하면 위 표가 맞는 것입니다.

1-2. 웹의 R번호와 보드 이름

  • R1~R8 = 보드 CH1~CH8 (릴레이)
  • R9~R16 = 보드 D1~D8 (MOS 출력)

1-3. 4자리 숫자판

8, 7, 10, 9번 핀에 연결돼 있다는 것만 확인됐고, 각 핀의 역할(데이터·클럭 등)과 표시 방법은 아직 확인되지 않았습니다. 이 웹 페이지에도 숫자판 기능은 없습니다. 판매처 설명서 파일의 시험 스케치를 확인한 뒤 따로 추가해야 합니다.

1-4. 핀 충돌 주의

✖ 키패드가 켜져 있으면 30~37번 핀을 키패드가 씁니다. 릴레이 31, 33, 35, 37번과 겹쳐서 릴레이가 안 움직이거나 멋대로 켜질 수 있습니다. 키패드를 쓰지 않으면 반드시 꺼 두세요(3-5 참고). 입력 IN9~IN16(32/30/28 등)도 키패드와 같은 핀대입니다.

2. 빠른 시작 (처음 한 번)

  1. Arduino IDE에서 DNMEB50_Mega2560_Firmware.ino를 보드(Arduino Mega 2560)에 업로드합니다. 확장 보드를 얹은 채 업로드가 막히면 확장 보드를 빼고 올린 뒤 다시 얹습니다.
  2. Arduino IDE의 시리얼 모니터와 다른 시리얼 프로그램을 모두 닫습니다. (포트를 하나만 쓸 수 있습니다.)
  3. 웹 페이지를 Chrome/Edge로 열고, 1. 연결 카드에서 Baud를 115200으로 두고 연결을 누른 뒤 포트를 고릅니다.
  4. 약 6초 기다립니다. 통신 로그에 ✅ 연결 및 보드 설정 불러오기 완료가 나와야 합니다. 그러면 보드에 저장된 릴레이 핀·키패드·입력 설정이 화면에 자동으로 채워집니다.
  5. 2. 릴레이 작동 방식에서 HIGH 신호일 때 ON을 고릅니다.
  6. DNMEB50 보드 버튼판에서 CH1을 눌러 K1이 딸깍하고 CH1 LED가 켜지는지 확인합니다. CH2~CH8도 차례로 확인합니다.
ℹ 웹에서 CH1을 눌렀는데 릴레이는 안 움직이고 오른쪽 MOS 단자(O1~O8)만 반응하면 릴레이와 MOS 핀 그룹을 서로 바꿔야 합니다.

3. 카드별 사용법

3-1. 맨 위: 처음이신가요? / 장치 선택 칩

① 연결 → ② 릴레이 방식 → ③ 릴레이 핀 → ④ 시퀀스, 이 네 가지만 하면 릴레이가 움직입니다. 그 아래 칩(키패드·초음파·로드셀·스텝모터·OLED 문구판)은 연결한 장치만 눌러서 해당 카드를 펼치는 용도입니다. ⓘ 설명 모두 펼치기를 누르면 각 카드의 도움말이 모두 열립니다.

3-2. 1. 연결

  • USB 연결: 위 빠른 시작 3번 그대로.
  • 블루투스: HC-05/HC-06을 Serial1(18/19번)에 배선하고 PC 블루투스에서 먼저 페어링하면 일반 COM 포트처럼 목록에 나타납니다. (19번은 IN8과 겹치니 주의)
  • 와이파이: 메가에는 와이파이가 없어서 별도의 ESP32에 ESP32_WiFi_Bridge.ino를 올려 Serial2(16/17번)에 연결해야 합니다. 메가 TX → ESP32 RX 방향은 5V를 3.3V로 낮추는 저항 분배기(예: 2kΩ+1kΩ)가 필요하고 GND는 공통으로 묶습니다. 비밀번호 없이 누구나 조작할 수 있는 방식이므로 인터넷에 포트를 열지 마세요.
  • USB와 블루투스/와이파이는 동시에 못 쓰고, 한쪽을 연결 해제 후 다른 쪽으로 연결합니다.

3-3. 2. 릴레이 작동 방식

릴레이 모듈이 HIGH에서 켜지는지 LOW에서 켜지는지 고릅니다. 이후 모든 ON/OFF 버튼과 시퀀스가 이 설정에 맞춰 신호를 자동으로 뒤집어 보냅니다. DNMEB50은 HIGH로 둡니다.

3-4. DNMEB50 보드 버튼판

보드 인쇄(CH1~CH8, D1~D8)와 같은 이름의 버튼입니다. 버튼마다 CH1, R1 · 핀 41처럼 보드 이름·채널·핀 번호가 표시되고, 켜진 릴레이는 초록색입니다. 버튼을 눌렀을 때의 동작은 체크박스로 고르며 체크한 것이 모두 실행됩니다.

체크박스기본동작
핀 번호 자동 입력켜짐해당 R번호의 핀을 보드 값으로 채움. 연결 중이면 보드에도 바로 저장
바로 ON/OFF켜짐누를 때마다 그 릴레이가 켜졌다 꺼짐
시퀀스 동작 단계에 추가꺼짐9번에서 열려 있는 시퀀스에 "릴레이 R번호 ON" 줄을 추가. 누를 때마다 줄이 늘어나므로 시퀀스를 만들 때만 켜세요

3-5. 3. 릴레이 R1~R16 핀 지정 · 수동 시험

  1. R1~R8은 41, 39, 37, 35, 33, 31, 29, 27, R9~R16은 43, 45, 47, 49, 50, 51, 52, 53이 들어 있어야 합니다. (이 보드용 펌웨어를 올리고 연결하면 자동으로 채워집니다. 카드의 기본값 A0~A15=54~69는 보드에 연결하지 않았을 때 보이는 예전 값입니다.)
  2. 바꿨다면 전체 적용(아두이노에 저장)을 눌러 보드 EEPROM에 저장합니다. 전원을 껐다 켜도 유지됩니다.
  3. 전원 투입 시 릴레이 시작 상태: 전체 OFF / 전체 ON / 부분 선택(체크한 것만 ON) 중 고릅니다. 일반적으로 전체 OFF가 안전합니다.
  4. 현재 설정 불러오기는 보드의 저장값을 화면에 다시 읽어오고, ⏻ 전체 소등은 R1~R16을 모두 끕니다. 🔄 보드 상태 새로고침은 실제 릴레이 상태를 다시 읽습니다.
  5. 여기의 ON/OFF 버튼은 배선 확인용 수동 시험입니다. 센서·버튼에 반응해 자동으로 움직이게 하려면 9번 시퀀스를 쓰세요.
⚠ 키패드 끄기: 5. 4x4 키패드 카드에서 "이 장치에 키패드를 연결해서 사용합니다" 체크를 끄고 핀 설정 적용(아두이노에 저장)을 누르세요. (DNMEB50 전용 펌웨어는 이미 꺼진 상태로 시작합니다.)

3-6. 4. 입력 채널 (버튼 · 스위치)

  • 입력 채널 개수를 정하고, 각 채널에 핀 번호와 이름을 적은 뒤 전체 적용(아두이노에 저장)을 누릅니다.
  • DNMEB50 입력은 NPN IN1~IN8 = 6/5/4/3/2/14/15/19, PNP IN9~IN16 = 32/30/28/22/23/24/25/26 입니다. 전용 펌웨어에는 이 값이 기본으로 들어 있어 연결하면 자동으로 불러옵니다.
  • ▶ 입력 상태 읽기로 한 번, 자동 새로고침(1초)을 켜면 계속 상태를 보여줍니다.
  • 🧪 가상 신호: 보드 없이 "🔒 눌린 채 유지"를 체크하거나 "🖱 가상 누르기"를 누르고 있으면 그 채널이 눌린 것처럼 동작해서, 기계 연결 전에 시퀀스를 시험할 수 있습니다. 🔄 리셋은 모든 가상 신호를 끕니다.

3-7. 5~8. 키패드 · 초음파 · 로드셀 · 스텝모터

해당 장치를 연결한 경우에만 쓰는 카드입니다. 맨 위 칩으로 열고, 카드에서 핀 지정 → 적용 순서로 설정합니다. 초음파는 TRIG/ECHO 핀, 로드셀은 핀 지정과 0점·보정을 먼저 마쳐야 시퀀스의 조건(거리 ≤/≥ cm, 무게 ≤/≥ g)으로 쓸 수 있습니다. DNMEB50의 비어 있는 핀을 고를 때는 1-1의 표와 겹치지 않게 하세요.

3-8. 10. LED 문구판 (OLED)

I2C OLED(20/21번 핀)를 연결했을 때만 씁니다. 시퀀스의 동작 단계로 문구를 표시할 수 있습니다. 20번은 보드의 KEY2, 21번은 KEY1과 겹치므로 OLED를 쓰면 보드 KEY1·KEY2 버튼은 사용할 수 없습니다.

3-9. 14. HMI 화면 (TJC 7인치 터치 화면)

기본으로 접혀 있습니다. TJC 터치 화면을 쓸 때만 열어 그 안의 사용설명서(준비물·배선·화면 제작·펌웨어·문제 해결)를 따르세요.

4. 9. 시퀀스 만들기

"무엇이 일어나면(시작 조건) → 어떤 조건에서만(인터록) → 무엇을 어떤 순서로(동작 순서)"를 정하는 기능입니다.

4-1. 만드는 순서

  1. ＋ 새 시퀀스를 누르고 시퀀스 이름을 적은 뒤 저장합니다.
  2. 시작 조건(트리거)을 고릅니다.
    • 수동 실행만: 자동 시작 없이 ▶ 지금 실행(테스트)으로만 실행
    • 누를 때(ON): 누르는 순간 1번만 실행(계속 눌려 있어도 반복 안 함)
    • 놓을 때(OFF): 떼는 순간 1번만 실행
    • 양쪽 다(BOTH): 누를 때와 놓을 때 둘 다 실행
    셀렉터 스위치는 "그 방향으로 돌리는 순간"으로 생각하면 됩니다.
  3. 트리거 채널(입력), 또는 키패드 코드·초음파·로드셀 조건을 지정합니다.
  4. 필요하면 🔒 추가 조건(인터록)을 넣습니다(4-2).
  5. 동작 순서에 ＋ 동작 추가로 줄을 추가합니다. 동작 종류는 릴레이, 스텝모터, OLED 문구, 로드셀 0점, 초음파 감시 켜기/끄기, 키패드 켜기/끄기, 계수계 리셋 중에서 고르며, 줄마다 지연·대기 시간을 줄 수 있습니다. 줄 왼쪽 ⠿ 손잡이를 끌거나 ▲▼ 버튼으로 순서를 바꿉니다.
  6. 필요하면 🔁 반복 횟수를 지정합니다(1 = 한 번만).
  7. 테스트(4-4) 후 ⚡ 전체 시퀀스를 보드에 저장합니다.

4-2. 추가 조건(인터록)

시작 조건이 일어나는 그 순간, 지정한 채널들이 모두 지정한 상태일 때만 실행합니다. ＋ 조건 추가로 늘립니다.

  • 예1) "CH2가 눌려 있을 때 CH3을 누르면 동작" → 시작 조건 CH3·누를 때 + 조건 CH2 눌림
  • 예2) "CH2와 CH3이 눌려 있을 때 CH5를 누르면 동작" → 시작 조건 CH5·누를 때 + 조건 CH2 눌림, CH3 눌림
  • 조건은 모두 맞아야(AND) 실행됩니다. 하나라도 틀리면 무시되고, 조건을 맞춘 뒤 트리거를 다시 눌러야 합니다. 조건 버튼만 누르는 것으로는 아무것도 실행되지 않습니다.
  • "눌림"은 ON, "뗌"은 OFF입니다. "뗌"으로 "이 버튼이 눌려 있지 않을 때만 실행" 같은 잠금을 만들 수 있고, "양쪽 다"는 항상 통과입니다.

4-3. 계수계(카운터)와 신호 매칭

  • 🔢 계수계: 채널 신호가 N번째일 때 실행합니다. 같은 채널·조건의 시퀀스를 횟수만 다르게 만들면(1번째→R1, 5번째→R2) 개수 세기에 쓸 수 있습니다. 카운트는 자동으로 0이 되지 않으니 동작 순서에 🔢 계수계 리셋 단계를 넣으세요.
  • 신호 매칭: ① 정확 매칭(목록 순서대로 와야 동작, 순서가 틀리면 처음부터) ② 랜덤 매칭(순서 상관없이 제한시간 안에 전부 오면 동작).

4-4. 테스트

  • 📡 실시간 신호 모니터: 연결하면 입력 핀 상태가 자동 표시됩니다. 🧪 가상 모드를 켜면 보드 없이 입력 칩을 눌러 "어떤 릴레이가 켜질지"를 화면에서만 계산해 보여줍니다(보드로는 아무것도 보내지 않음). 가상 모드는 일반 채널 트리거 + 릴레이 줄만 계산합니다.
  • ▶ 지금 실행(테스트)은 동작 순서를 즉시 실행하고, ■ 테스트 초기화로 돌립니다.
  • ▶ PC 자동 감시 시작: 이 PC에서 웹 페이지가 연결된 동안만 시퀀스가 자동 동작합니다. 감시 주기(ms)를 조절하고 ■ 감시 중지로 끕니다. 테스트용이며 PC를 끄면 멈춥니다.
  • ⬇ 전송될 명령 미리보기: 보드에 저장할 때 나가는 명령(SEQCLR/SEQTRIG/SEQSTEP 등)을 보드 전송 없이 텍스트로 저장합니다. 저장 후 이상하면 이 파일에서 채널 번호·핀·지연 값을 먼저 확인하세요.

5. PC 없이 혼자 동작시키기 (독립 작동)

  1. 시퀀스를 만들고 테스트로 확인합니다.
  2. ⚡ 전체 시퀀스를 보드에 저장을 누르면 시퀀스가 보드 EEPROM에 통째로 기록됩니다.
  3. 이후 PC를 끄고 전원(USB 또는 외부 어댑터)만 연결해도 보드가 스스로 입력을 감시하고 실행합니다.
⚠ 용량 제한: 최대 시퀀스 14개 × 시퀀스당 12단계입니다. 반복을 지정하면 반복한 단계가 모두 펼쳐져 저장되므로 (단계 수 × 반복 횟수)가 12를 넘으면 뒤쪽이 잘린다는 경고가 나옵니다. 화면 도움말에는 외장 I2C EEPROM(AT24C256)이 필요하다고 적혀 있으니, 저장이 안 되면 먼저 12번 카드의 "실제 I2C 연결 상태 확인"을 눌러 보세요.

순수 아두이노용 .ino 만들기

⬇ 아두이노 스케치(.ino) 만들기는 웹 연결 없이 Arduino IDE로 바로 올릴 수 있는 파일을 만듭니다(현재 화면의 핀·릴레이 방식·시퀀스 기준). 입력 채널 트리거 + 추가 조건 + 릴레이/스텝모터 동작 + 지연만 들어가고, 키패드 코드·초음파·로드셀 트리거 시퀀스는 제외됩니다(만들 때 제외 목록을 알려줍니다).

⚠ 이 스케치를 올리면 보드의 웹 제어용 펌웨어가 대체됩니다. 웹으로 다시 제어하려면 DNMEB50_Mega2560_Firmware.ino를 다시 올려야 합니다.

6. 점검 · 진단 (11~13번 카드)

6-1. 11. 테스트 · 문제 진단

  • ▶ 테스트 시작: 실제 버튼을 누르면 시퀀스의 "트리거 → 동작 순서"가 묶여서 표시되고, 켜지는 것을 한눈에 볼 수 있습니다.
  • 핀 원시 상태 확인: 4번 카드에 등록하지 않은 핀도 번호만 넣으면 눌렸는지 바로 보여줍니다. 내부적으로 INPUT_PULLUP으로 읽으므로 핀↔GND로 연결되는 구조를 가정합니다. DNMEB50의 절연 입력(옵토) 신호가 안 읽히면 이 방식과 맞지 않을 수 있습니다.
  • 🔍 자동 감지: 핀 번호를 몰라도 버튼을 눌러 보면 눌린 핀(D몇 번)과 등록된 채널·시퀀스를 알려줍니다. 릴레이 출력 핀과 키패드 핀은 안전을 위해 자동 제외됩니다.
  • 🔧 전체 점검: 시작 후 약 3.5초 동안 아무것도 누르지 마세요. 그동안 값이 흔들리는 핀을 노이즈·플로팅 문제로 판단해 원인과 해결 방법을 알려줍니다.
  • 📡 실시간 모니터링 & 작동 기록: 입력이 켜지고 꺼질 때, 릴레이가 움직일 때마다 시간과 함께 기록합니다. 짧은 시간에 반복적으로 흔들리면 접촉불량·노이즈로 의심해 알려줍니다. ⬇ 기록 파일로 저장으로 보관할 수 있습니다.

6-2. 12. 배선도 (자동 생성)

3·4·5번 카드의 핀 설정으로 배선도를 그리고, 같은 핀을 겹쳐 쓰거나 고정 용도 핀(USB 통신 0·1번, I2C 20·21번)을 잘못 고른 곳을 빨간색으로 표시합니다. 실제 전선을 카메라로 보는 것이 아니라 설정값끼리의 충돌 검사입니다. 🔌 실제 I2C 연결 상태 확인으로 OLED·외장 EEPROM 연결도 확인합니다.

6-3. 13. 설정 전체 인쇄 / PDF 저장

릴레이 핀·이름, 입력 채널, 키패드, 시퀀스, OLED 설정을 한 장으로 인쇄하거나 PDF로 저장합니다. 설정을 마친 뒤 한 번 저장해 두면 보드 교체나 재설정 때 도움이 됩니다.

7. 문제 해결

증상확인할 것
연결 버튼을 눌러도 포트가 안 보임Chrome/Edge인지, USB 케이블이 데이터용인지, Arduino IDE 시리얼 모니터가 열려 있지 않은지 확인
연결은 되는데 설정이 안 채워짐연결 후 6초 이상 기다리기. 로그의 "설정 불러오기 완료" 확인. 펌웨어를 올렸는지, Baud가 115200인지 확인
R1을 눌러도 K1이 안 움직임릴레이 방식이 HIGH인지, R1 핀이 41인지, 보드 전원(12V/24V)이 들어와 있는지 확인. 키패드가 켜져 있으면 끄기
R1을 눌렀더니 오른쪽 MOS 단자(O1)만 반응릴레이 그룹과 MOS 그룹 핀이 바뀐 것. 릴레이 핀과 MOS 핀을 서로 바꿔 입력
일부 릴레이가 멋대로 켜짐/안 켜짐키패드 핀(30~37)과 겹침. 키패드 사용 체크 해제 후 적용
입력이 눌러도 변화 없음4번 카드의 핀 번호, NPN(IN1~8)/PNP(IN9~16) 센서 종류 확인. 11번 "핀 원시 상태 확인"과 "자동 감지"로 실제 핀이 반응하는지 확인
입력이 혼자 깜박임11번 "전체 점검"으로 노이즈·플로팅 진단. 배선 길이·접지 확인
시퀀스가 PC에서는 되는데 보드에서는 안 됨저장 후 "보드에서 불러오기" 확인. 14개/12단계 제한과 "명령 미리보기" 파일 확인. 키패드·초음파·로드셀 트리거는 .ino 변환에서 제외됨
전원을 껐다 켜니 릴레이가 켜져 있음3번 카드의 "전원 투입 시 릴레이 시작 상태"를 전체 OFF로 설정 후 저장

8. 안전 및 주의

  • 릴레이 접점에 220V 등 고전압을 연결할 때는 반드시 전원을 차단한 상태에서 배선하고, 처음 시험은 부하 없이 딸깍 소리와 LED만 확인하세요.
  • 모터·실린더 등 위험한 기계는 시퀀스를 충분히 시험하기 전에 연결하지 마세요. 비상정지 수단은 웹 화면이 아니라 별도의 물리 스위치로 두는 것이 안전합니다.
  • 와이파이 연결은 암호화·인증이 없으므로 공유기 포트포워딩으로 외부에 공개하지 마세요.
  • 보드 전원을 연결할 때 12V/24V 버전 표시를 확인하세요.
  • 판매처는 제공하는 스케치를 시험용으로만 안내하고 추가 코드·기술 지원은 하지 않습니다. 숫자판 등 미확인 기능은 판매처 자료로 먼저 확인하세요.
