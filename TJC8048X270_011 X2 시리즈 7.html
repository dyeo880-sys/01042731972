TJC 화면 편집 도구 (800×480)

미리보기에서 버튼을 끌어 옮기고, 오른쪽 아래 노란 모서리로 크기를 바꿉니다.

방향키: 선택한 버튼 이동 (Shift는 10px) · Delete: 삭제 · Ctrl+D: 복제 · 버튼을 두 번 누르면 글자 수정 · 버튼/글자를 오른쪽 클릭하면 글꼴·색상·핀 번호·연결 페이지·신호 받을 때 메뉴가 뜹니다.

선택한 버튼

핀 번호란? 이 버튼이 담당하는 아두이노 메가의 핀 번호입니다.

  • 릴레이·일반 버튼의 핀 번호는 배선 메모용입니다. 버튼 목록과 "편집기에 넣을 내용"에 "연결 핀: N"으로 적혀 나옵니다. 릴레이 버튼은 아두이노 업로드용 저장(.ino)에 이 핀을 화면 버튼을 뗄 때마다 켜고 끄는 코드가 자동으로 들어갑니다. 일반 버튼은 이 칸만으로 digitalWrite가 들어가지 않습니다.
  • 핀을 실제로 켜고 끄려면
    ① 메가 → 화면 방향: 오른쪽 클릭 메뉴 "신호 받을 때"에서 "핀 번호 작동"을 체크하면 메가 코드(tjcSignalN)에 pinMode/digitalWrite가 자동으로 들어갑니다.
    ② 화면 버튼 → 핀 방향: 버튼에 "신호 문자"를 넣으면 "버튼 신호" 코드가 만들어집니다. 그 onSignal() 안의 TODO 자리에 digitalWrite(핀, HIGH 또는 LOW)를 직접 넣으세요.
  • 화면 자체의 IO_0~IO_7(화면 뒤 위쪽 10핀)은 별개입니다. 이 메뉴의 "화면 IO 작동"에서 고르면 편집기에 넣을 코드(pioN=1/0)와 cfgpio 설정이 만들어집니다. 메가 핀 번호가 아닙니다.
  • 스텝 모터의 STEP/DIR/EN 핀은 스텝 모터 코드에 그대로 들어갑니다.
  • 범위는 0~99입니다. 메가 2560에서는 0·1번(USB 통신)과 14~19번(Serial3·2·1 통신)은 피하세요. 화면과 Serial1로 연결하면 18·19번은 화면 선입니다.

타이머 (이 페이지)

신호 받기 (메가 → 화면)

신호 받기 (메가 → 화면): 센서 등을 읽은 메가가 tjcSignalN() 함수를 부르면 화면이 동작합니다.

  • 배선: 화면 TX → 메가 RX1(19번), 화면 RX → 메가 TX1(18번), GND끼리 연결. 연결(Serial)과 속도는 화면 설정과 같아야 합니다.
  • 실행 시점 정하기: 오른쪽 클릭 메뉴의 "메가 입력 핀"에 번호를 넣으면 그 디지털 핀이 HIGH(또는 LOW)가 되는 순간 자동으로 실행됩니다. 센서 출력선을 메가의 그 핀과 GND에 연결하면 됩니다. 핀을 비우면 직접 만든 코드에서 tjcSignalN()을 불러야 합니다. 메가 코드의 setup()에 tjcPinSetup();, loop()에 tjcPinWatch(); 가 필요합니다(.ino 저장은 자동).
  • 동작은 부품을 오른쪽 클릭해 "신호 받을 때"에서 체크합니다. 글자 바꾸기·페이지 이동·다른 버튼 작동·핀 번호 작동을 한꺼번에 실행할 수 있습니다.
  • USB로 연결해 두면, 아두이노가 신호의 사건 이름(또는 S1, 신호1)을 한 줄 보냈을 때 시험 모드에서 그 신호가 실행됩니다.
  • "메가 코드 복사"를 Arduino IDE에 붙여 넣고 setup()에 Serial1.begin(속도); 를 추가하세요.

편집기에 넣을 내용

저장

"폴더에 저장"은 폴더를 한 번 고르면 .ino, 작업 파일(.json), 편집기 코드, 페이지별 배경 PNG를 그 폴더에 한꺼번에 넣어 줍니다. USB 안에 새 폴더를 만들어 그 폴더를 고르세요. Chrome 또는 Edge에서만 됩니다.
.ino 파일 하나에 아두이노 코드와 작업 설정이 함께 들어갑니다. 나중에 아래 "작업 불러오기"에서 이 .ino를 열면 이어서 수정할 수 있습니다. 배경 그림은 .ino에 들어가지 않으니, 배경까지 다른 컴퓨터로 옮기려면 "작업 저장 (.json)"도 함께 보관하세요.

작업이 끝나면 적용하는 방법

  1. 이 도구에서 저장 "이 페이지 배경 PNG 저장"을 페이지마다 누릅니다. 편집기에 진짜 버튼을 올릴 거면 "PNG에 버튼 틀 그리기"를 끄고 저장하세요. "전체 페이지 코드 저장"으로 editor_codes.txt도 받고, "작업 저장"도 눌러 두세요.
  2. TJC 편집기(USART HMI)에서 새 프로젝트 기종은 TJC8048X270_011을 고르고, 화면 방향은 800×480 가로로 맞춥니다.
  3. 배경 그림 넣기 편집기의 그림 창에서 저장한 PNG를 추가합니다. 해당 페이지를 선택하고 배경을 "그림"으로 바꾼 뒤 방금 넣은 그림을 고릅니다.
  4. 글자 확인 "+ 글자"로 만든 글자 중 "PNG 그림에 글자 넣기"가 켜진 것은 배경 PNG에 이미 들어 있어서 편집기에서 할 일이 없습니다. 껐다면 코드 칸의 내용대로 Text 부품을 올립니다.
  5. 버튼 올리기 도구상자의 Button을 화면에 올리고, 속성에서 x, y, 너비, 높이를 이 도구의 "버튼 목록" 표 값 그대로 넣습니다. 글자는 txt 칸에 넣습니다.
  6. 동작 코드 넣기 버튼을 선택하고 Touch Release Event(손 뗄 때 실행) 칸에 이 도구가 보여주는 한 줄(예: page 1)을 붙여 넣습니다. 릴레이 버튼은 코드 대신 Send Component ID를 체크합니다.
  7. 타이머 넣기 (사용할 때만) Timer 부품을 올리고 tim, en 값을 넣은 뒤 Timer Event 칸에 코드 한 줄을 붙여 넣습니다.
  8. 편집기에서 먼저 시험 편집기의 디버그(시뮬레이터)로 버튼을 눌러 화면이 넘어가는지 확인합니다. 이 도구의 "시험 보기"와 같은 결과여야 합니다.
  9. 화면에 올리기 컴파일한 뒤 USB-TTL로 다운로드하거나, 만들어진 .tft 파일을 microSD에 복사해 화면에 꽂고 전원을 껐다 켭니다.
  10. 메가에 올리기 (신호를 쓸 때만) "메가 코드 복사" 내용을 Arduino IDE에 붙여 넣고 setup() 안에 Serial1.begin(9600); 줄을 추가한 뒤 업로드합니다. 배선은 화면 TX → 메가 RX1(19번), 화면 RX → 메가 TX1(18번), GND끼리 연결입니다. 화면 속도(baud)와 코드의 속도가 같아야 합니다.

편집기 버전에 따라 메뉴 이름이 조금 다를 수 있습니다.

화면 뒤 접속부와 배선 안내 (TJC8048X270_011)

사진으로 확인한 것과 확인하지 못한 것을 나눠 적었습니다. "미확인"은 구입처 핀 표나 설명서로 꼭 확인하세요.

  1. 위쪽 10핀 접속부 (보드에 GND, IO_0~IO_7, 3.3V 인쇄) 화면 자체의 입출력 핀입니다. 아두이노 핀이 아닙니다.
    · 3.3V 신호이고 전류가 작습니다. 릴레이 코일이나 모터를 직접 연결하지 말고 릴레이 모듈이나 트랜지스터를 거치세요.
    · 5V 신호를 넣으면 보드가 상할 수 있습니다.
    · 얇은 플랫 케이블용 접속부라 점퍼선이 바로 꽂히지 않습니다. 핀 간격에 맞는 케이블이나 변환 기판이 필요합니다.
    · 이 IO 핀은 버튼을 오른쪽 클릭 → "화면 IO 작동"(누르면 화면이 직접 켜고 끔) 또는 "신호 받을 때 → 화면 IO 작동"(메가 신호로 켜고 끔)에서 설정합니다. 아래 "화면 IO 핀 작동 방법"을 보세요.
  2. 왼쪽 아래 4핀 접속부 (케이블이 꽂혀 있음) - 미확인 4가닥 케이블이라 전원 5V, TX, RX, GND 연결일 가능성이 있지만 확인되지 않았습니다.
    · 확인하기 전에는 케이블을 뽑지 마세요.
    · 확인 방법: 케이블 반대쪽 끝의 글자를 보거나, 구입처 핀 표를 보거나, 전원을 끈 상태에서 멀티미터로 GND 연결을 확인합니다.
  3. 왼쪽 위 6핀 접속부 (비어 있음) - 미확인 핀 이름이 인쇄되어 있지 않습니다. 용도를 확인하기 전에는 아무것도 연결하지 마세요.
  4. 아두이노 메가와 연결 (이 도구 기준) · 화면 TX → 메가 RX1(19번), 화면 RX → 메가 TX1(18번)으로 교차 연결하고, GND끼리 연결합니다.
    · Serial2를 고르면 RX2(17번), TX2(16번), Serial3이면 RX3(15번), TX3(14번)입니다.
    · 화면 속도(baud)와 코드의 속도가 같아야 합니다.
    · 화면 전원 전압과 전류는 설명서에서 확인하세요. 7인치 화면은 전류를 많이 쓰는 편이라 메가의 USB 전원에만 의존하지 말고 별도 전원을 권장합니다.
    · "아두이노 업로드용 저장 (.ino)"로 만든 파일에는 setup()과 loop()가 이미 들어 있어서 따로 줄을 추가할 필요가 없습니다.
  5. 작업 전 확인 · 배선과 케이블 작업은 전원을 모두 끈 상태에서 합니다.
    · 플랫 케이블은 방향과 1번 핀 위치를 확인하고 잠금 장치를 닫습니다.
    · 핀 용도를 확인하기 전에 전원을 켜지 마세요.
위쪽 10핀(IO_0~IO_7) 장착 방법과 구입할 부품

이 접속부는 핀 헤더가 아니라 FPC/FFC(얇은 플랫 케이블)용 잠금식(ZIF) 접속부입니다. 그래서 "잭을 꽂는다"기보다 플랫 케이블을 끼워 잠그고, 반대쪽에서 점퍼선으로 빼는 방식으로 연결합니다. 사진만으로 규격을 확정할 수 없어 아래 "구입 전 확인"을 꼭 먼저 하세요.

  1. 구입 전 확인 (가장 중요) · 핀 간격(피치): 접속부 핀 10개 중 양 끝 핀 중심 사이 거리를 자(또는 버니어 캘리퍼스)로 재서 9로 나눕니다. 약 9mm면 1.0mm, 약 4.5mm면 0.5mm입니다. 사진 속 핀 간격으로는 1.0mm로 보이지만 직접 재서 확인하세요.
    · 핀 수: 10핀(P10).
    · 케이블 두께: 보통 0.3mm(접점 보강판 포함). 구입처 설명에 "0.3mm"라고 적힌 것을 고르세요.
    · 접점 방향: 접속부가 위 접점인지 아래 접점인지는 사진으로 알 수 없습니다. 아래 두 종류(같은 방향 / 반대 방향) 중 한 쪽만 맞을 수 있으니 두 종류를 모두 2~3개씩 사거나, 구입처에 "TJC X2 7인치 IO 포트용"이라고 문의하세요.
  2. 구입할 제품 (검색어) ① FFC/FPC 플랫 케이블 10P 1.0mm (길이 5~10cm, 같은 방향 'A타입'과 반대 방향 'B타입' 두 종류)
    ② FPC/FFC 1.0mm 10P → 2.54mm 변환 기판 (브레이크아웃 보드, 잠금식 ZIF 소켓 + 핀 헤더 포함)
      · 검색어 예: "FFC FPC 1.0mm 10P 2.54mm 변환 기판", "FPC 1.0mm 10핀 어댑터 보드 DIP", "FFC 10P 1.0mm breakout"
    ③ 점퍼선 (암-암 또는 암-수, 2.54mm 핀 간격)
    ④ 릴레이 모듈(3.3V 입력 가능) 또는 NPN 트랜지스터/MOSFET + 저항 (IO 핀은 전류가 작아 부하를 직접 연결할 수 없음)
    · 구입처: 알리익스프레스, 디바이스마트, 아이씨뱅큐, 엘레파츠, 쿠팡 등에서 위 검색어로 찾으면 됩니다. 정확한 판매 제품명은 구입처마다 달라서, "1.0mm / 10P / ZIF" 세 가지가 맞는지만 확인하세요.
  3. 반대쪽(케이블 끝)에 장착할 부품과 제품 이름 케이블의 화면 반대쪽 끝에는 "FFC/FPC 1.0mm 10P → 2.54mm 변환 기판 (어댑터 보드)"를 연결합니다. 이 기판에 핀 헤더가 달려 있어 점퍼선을 바로 꽂을 수 있습니다.
    ① 반대쪽 변환 기판 (찾아볼 제품 이름)
      · "FFC / FPC Adapter Board 1mm to 2.54mm Soldered Connector – 10 pin" (모델 표기 FPCA1T254-10, 해외 판매처 Robu 등)
      · "10p 1.0mm ffc fpc adapter board" (해외 판매처 Hubtronics 등)
      · 국내 검색어: "FFC FPC 1.0mm 10P 2.54mm 변환기판", 디바이스마트 "SMT/FFC/FPC 변환기판" 분류
    ② 케이블 (찾아볼 제품 이름)
      · 디바이스마트 "FFC/FPC 케이블 1.0mm/10P/20㎝" (NW3 제품, 20cm)
      · 디바이스마트 "변환용 FPCB [FPC10P100mm-10P]" (1.0mm, 10핀, 100mm)
    ③ 점퍼선: 암-암 듀퐁 점퍼선 (2.54mm)
    주의: 위 제품 이름과 규격(1.0mm, 10핀, 길이)은 판매 페이지에서 확인했지만, 접점 방향(같은 방향/반대 방향)과 어댑터 기판의 잠금식 소켓 여부는 페이지에서 확인하지 못했습니다. 주문 전에 판매처에 "화면 IO 포트(상부 접점/하부 접점) 연결용"이라고 문의하거나, 케이블을 두 종류 사서 맞는 것을 쓰세요. 어댑터 기판이 납땜 방식(소켓 없이 케이블을 직접 납땜)인 제품이면 이 용도에 쓰기 어려우니 "ZIF 소켓 포함"인 것을 고르세요.
    연결 구성: 화면 IO 접속부 ⇄ [플랫 케이블 1.0mm 10P] ⇄ 변환 기판의 ZIF 소켓 ⇄ 핀 헤더 ⇄ 점퍼선 ⇄ 릴레이 모듈 등
  4. 핀 순서 (보드에 인쇄된 순서) GND, IO_0, IO_1, IO_2, IO_3, IO_4, IO_5, IO_6, IO_7, 3.3V (한쪽 끝이 GND, 반대쪽 끝이 3.3V)
    플랫 케이블을 변환 기판에 끼울 때 같은 쪽 끝이 GND가 되도록 방향을 맞춥니다. 반대로 끼우면 3.3V가 GND 자리에 들어가 합선됩니다.
  5. 장착 방법 (단계별) ① 화면과 아두이노의 전원을 모두 뽑습니다.
    ② 접속부의 검은(또는 흰) 잠금 레버(액추에이터)를 손톱이나 얇은 핀셋으로 살짝 위로 들어 올려 엽니다. (힘주어 꺾지 말고 90°쯤 세웁니다. 부러지면 수리가 어렵습니다.)
    ③ 플랫 케이블의 금속 접점이 보이는 면을 기판의 접점 쪽으로 향하게 해, 끝까지 수평으로 밀어 넣습니다. 접점 금속 부분이 소켓 밖으로 거의 보이지 않아야 합니다.
    ④ 케이블이 삐뚤지 않은지(양쪽 가장자리 간격이 같은지) 확인하고, 잠금 레버를 눌러 닫습니다. "딸깍" 하는 느낌이 납니다.
    ⑤ 케이블 반대쪽 끝도 변환 기판의 ZIF 소켓에 같은 순서로 끼우고 잠급니다. (GND가 같은 쪽 끝)
    ⑥ 변환 기판의 2.54mm 핀 헤더에 점퍼선을 꽂아 필요한 IO_n, GND, 3.3V를 뺍니다.
    ⑦ 전원을 켜기 전에 멀티미터 도통(삐 소리) 모드로 3.3V와 GND가 서로 붙어 있지 않은지 확인합니다.
  6. 화면 IO 핀 작동 방법 (IO_0~IO_7 켜고 끄기) 화면 뒤 10핀 접속부의 IO_0~IO_7은 화면이 직접 3.3V 출력/입력으로 쓰는 핀입니다. 사용 순서:
    ① 버튼을 오른쪽 클릭하고 "화면 IO 작동"에서 IO_번호와 동작(켜기 / 끄기 / 누르는 동안 켜기)을 고릅니다.
    ② 오른쪽 "편집기에 넣을 내용"에 나오는 page 0 Preinitialize Event의 cfgpio N,2,0 줄을 TJC 편집기 page 0의 Preinitialize Event(시작할 때 실행) 칸에 붙여 넣습니다. 이 줄이 해당 IO를 출력 모드로 만듭니다.
    ③ 같은 버튼의 pioN=1(켜기) 또는 pioN=0(끄기) 줄을 그 버튼의 Touch Release Event(누르는 동안 켜기는 Press와 Release 두 칸)에 붙여 넣습니다.
    ④ 메가에서 켜고 끄려면 "신호 받을 때"의 "화면 IO 작동"을 체크하세요. 메가 코드(tjcSignalN)에 cfgpio와 pioN=값 명령이 자동으로 들어갑니다.
    ⑤ 출력은 3.3V이고 전류가 작으니 릴레이 모듈이나 트랜지스터를 거쳐 부하를 구동하세요. 이 도구의 "시험 보기"는 화면의 실제 핀을 움직이지 않고 안내 문구만 보여 줍니다.
    확인 필요: cfgpio의 두 번째 값(모드 번호, 여기서는 출력 모드로 2 사용)은 TJC 설명서 사이트에 접속이 되지 않아 확인하지 못했습니다. 편집기에서 시험할 때 핀이 안 움직이면 TJC 설명서(wiki.tjc1688.com)의 cfgpio 항목에서 "출력 모드" 번호를 확인해 바꾸세요. 사용 중인 편집기 버전이 pio 변수를 지원하는지도 함께 확인하세요.
  7. "핀 분리기"(변환 기판)란? 작은 접속부에 핀을 어떻게 넣나요 접속부에 핀을 직접 넣는 것이 아닙니다. 접속부에는 얇은 플랫 케이블(FFC)의 끝만 끼우고, 케이블 반대쪽 끝을 변환 기판에 끼워 굵은 핀(2.54mm)으로 바꿔 씁니다.
    화면 접속부(작음) ← 플랫 케이블 → 변환 기판 → 굵은 핀 → 점퍼선
    · 변환 기판 검색어: "FFC FPC 1.0mm 10P 변환기판", "FPC 1.0mm 10핀 2.54mm 어댑터 보드", 영어 "10P 1.0mm FFC FPC adapter board", 디바이스마트 "SMT/FFC/FPC 변환기판" 분류
    · 케이블 검색어: "FFC 케이블 1.0mm 10P" (길이 10~20cm)
    · 고를 때 확인: ① 1.0mm, 10P ② ZIF 잠금 소켓이 있는 기판(케이블을 직접 납땜해야 하는 기판은 피함) ③ 핀 헤더(2.54mm)가 납땜되어 있는지(납땜이 안 된 제품은 같이 든 핀을 직접 납땜해야 함)
    · 접속부 쪽과 변환 기판 쪽 모두 ZIF 잠금 레버를 들어 올려 케이블을 끝까지 평평하게 밀어 넣고 눌러 닫습니다. 안 맞으면 케이블을 뒤집거나, 같은 방향/반대 방향 케이블을 바꿔 보세요.
  8. 핀 연결: 변환 기판 → 릴레이 모듈 (예: IO_3으로 릴레이 켜고 끄기) 변환 기판의 수핀에 암-암 점퍼선으로 릴레이 모듈의 수핀을 이어 줍니다.
    · 릴레이 모듈 IN(S, SIG) ← 변환 기판 IO_3 (도구에서 고른 IO 번호와 같아야 함)
    · 릴레이 모듈 GND(-) ← 변환 기판 GND
    · 릴레이 모듈 VCC(+) ← 모듈이 요구하는 전원. 3.3V 전용 모듈이면 변환 기판 3.3V, 5V 모듈이면 별도 5V 전원의 +(이때 별도 전원 GND도 변환 기판 GND와 이어 공통으로 잡습니다)
    · 변환 기판 핀 순서는 케이블 방향에 따라 뒤집힐 수 있으니 연결 전에 GND가 어느 쪽 끝인지 확인합니다.
    · 부하 쪽: 릴레이 나사 단자 COM에 부하 전원의 한 선, NO에 부하를 연결합니다. (평소 끊김 → 동작하면 연결. NC는 반대) 부하 전원 − 는 부하의 다른 쪽에 연결합니다.
    · 시험은 "누르는 동안 켜기"로 하면 안전합니다. 눌렀는데 꺼진다면 모듈이 Low Level 트리거일 수 있으니 모듈의 High/Low 점퍼를 High로 바꾸거나 도구의 동작을 "끄기"로 바꿔 보세요.
    · 220V를 직접 다루는 작업은 전원을 끄고 전기 지식이 있는 분이 하며, 먼저 12V·24V 등 낮은 전압으로 시험하세요.
  9. 릴레이 모듈 구입 (3.3V 신호로 동작하는 제품) · 구입 조건: ① 3.3V 로직(3.3V 트리거 가능) ② High Level 트리거이거나 High/Low 선택형 ③ 접점 용량이 부하보다 큼 ④ 입력 전류가 작은 포토커플러 입력형이 유리(화면 IO 핀의 정확한 출력 전류는 확인하지 못했습니다)
    · 확인된 예: "1-channel relay module, 3.3V, Low Level"(Sigmanortec, 3.3V 전원·신호, Low Level 트리거라서 입력이 GND일 때 동작. 접점 용량은 페이지에 없음) / 디바이스마트 "아두이노 2채널 5V 릴레이 모듈 Trigger 선택형 [SZH-RLBG-042]"(점퍼로 High/Low 선택, 10A 250VAC·10A 30VDC. 3.3V 구동 가능 여부는 페이지에 없어 판매처 문의 필요, 5V 전원 별도 필요)
    · 검색어: "릴레이 모듈 3.3V 1채널 포토커플러 High Low 트리거", 영어 "Relay Module 3V and 3.3V Logic Dual Optocoupler Isolation High and Low Trigger 1 Channel"
  10. 사용할 때 주의 · IO 핀은 3.3V 신호, 작은 전류입니다. 5V 장치를 직접 연결하지 마세요. 5V를 받는 입력은 레벨 변환(또는 분압)을 거치세요.
    · 릴레이/LED/모터는 트랜지스터나 릴레이 모듈을 거쳐 구동하고, 부하 전원은 따로 씁니다. 화면 GND와 부하 쪽 GND는 연결해 공통으로 잡습니다.
    · 이 IO 핀의 동작은 이 도구에서 만든 코드를 TJC 편집기(USART HMI)에 붙여 넣어 적용합니다. 방법은 아래 "화면 IO 핀 작동 방법"을 보세요.
    · 케이블은 여러 번 접었다 폈다 하지 말고, 한 번 끼운 뒤에는 접속부에 힘이 걸리지 않도록 테이프 등으로 고정합니다.
  11. 납땜해서 쓰고 싶다면 (선택) 플랫 케이블에 바로 납땜하는 것은 피하세요. 접점이 쉽게 들뜨거나 끊어집니다. 반드시 위의 ② 변환 기판을 쓰고, 핀 헤더(2.54mm) 납땜이 필요하면 땜납 온도 320~350°C로 핀당 2~3초 이내로 짧게 하세요.
  12. 호환 여부를 모를 때 접속부 옆면이나 보드 뒷면의 글자(품번)를 사진으로 찍어 구입처(TJC 판매처)에 "IO 확장 포트 케이블/어댑터 품번"을 물어보면 가장 확실합니다. 케이블 규격이 다르면 소켓에 억지로 밀어 넣지 마세요.
