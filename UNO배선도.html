Arduino UNO 릴레이 배선도

① 릴레이 출력 배선 (UNO → 릴레이 모듈 → 부하)

② 입력 신호 배선 — 두 가지 방식 (D핀과 5V가 만나면 신호)

정리
· 릴레이: UNO D3~D6 → 모듈 IN1~IN4, 모듈 VCC=5V, GND=GND(공통). 기본은 LOW일 때 릴레이 ON(Active-LOW 모듈). 반대로 동작하면 프로그램의 "출력 반전"을 켜세요.
· 입력 기본 방식(A): 스위치 한쪽 = 핀, 반대쪽 = GND. 누르면 LOW = 눌림. 가장 안전하고 간단합니다.
· 5V 방식(B): 프로그램에서 해당 CH의 "입력 반전"을 켠 경우입니다. 핀이 HIGH(5V)일 때 눌림으로 읽습니다. 핀은 내부 풀업이 켜져 있어 스위치가 열려 있을 때 HIGH가 되므로, 핀과 GND 사이에 4.7kΩ(풀다운)을 꼭 넣어야 "떼면 LOW"가 됩니다. 5V 쪽 스위치에는 1kΩ 직렬을 넣어 보호하세요. 이 저항값은 제가 계산한 권장값이니, 연결 후 ② 탭에서 눌림/뗌이 맞게 표시되는지 확인해 주세요.
· 센서 출력이 이미 5V/0V를 확실히 내보내는 타입(NPN/PNP 5V 출력 등)이면 풀다운 없이 센서 신호선을 핀에 바로 연결해도 됩니다. 이때도 센서 GND는 UNO GND와 공통이어야 합니다.
· 24V 신호는 절대 핀에 직결하지 마세요. 포토커플러나 릴레이로 분리해서 받아야 합니다.
